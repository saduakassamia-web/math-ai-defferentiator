# AI for Differentiated Learning - Assignment Report

## Project Overview
This web application leverages AI-driven prompt structures to adapt the core mathematical topic **"Short Multiplication Formulas" (Қысқаша көбейту формулалары)** into 3 distinct difficulty tiers for differentiated learning[cite: 1].

## Differentiation Levels
1. **Level 1 (Foundation):** Simplified context, direct prompts, and step-by-step guided breakdown for struggling learners[cite: 1].
2. **Level 2 (Standard):** Standard grade-level curriculum problem-solving focusing on expression simplification[cite: 1].
3. **Level 3 (Advanced):** Multi-step logic challenge connecting algebraic identities with fractional equations[cite: 1].

## AI Prompt Engineering Strategy
The AI component is designed using system prompts that instruct the LLM to adjust cognitive load, scaffold hints dynamically, and provide targeted feedback based on the selected tier.
